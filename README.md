# Phalanx

盾を並べて守り、号令で一斉に突く。古代ギリシャの重装歩兵の密集隊形（ファランクス）をテーマにした、ブラウザで動く小さなゲームです。

## 遊び方

- **本編（スプライト版）**：`game.html`。筋肉隆々の重装歩兵とペルシャ兵の絵を、`src/game.js` のルールで動かします。ローカルサーバー経由で開いてください。
- **2D版**：`index.html` をブラウザで開くだけで遊べます。
- **3D版（試作中）**：`3d.html`。ES モジュールを使うので、ファイルを直接開くのではなく、ローカルサーバー経由で開いてください（例：`python3 -m http.server` のあと `http://localhost:8000/3d.html`）。GitHub Pages ではそのまま動きます。

- **スプライト確認（試作中）**：`sprites.html`。筋肉隆々の兵（味方）とペルシャ兵（敵）の絵をコマ送りで動かす疑似3D版の動作確認ページです（スペース：味方が全員で突く、D／E：味方／敵の誰かが倒れる、A：自動切り替え）。絵は `tools/make_sprites.py` で `assets/sprites/raw/` の緑背景のシートから切り出しています。

ゲームのルールは `src/game.js` にまとめてあり、見た目（2D・3D）や入力（キーボード・スマホ）と分けています。

- **スペースキー（またはクリック／タップ）**：隊全体で一斉に突く
- **それ以外**：ずっと盾で守る（突いている間だけ無防備になる）
- **R キー**：リセット

## ルール

- 味方は横一列に並び、倒れると後ろの予備兵が前に出て埋めます。
- 敵は一人ずつバラバラのタイミングで「守り → 攻撃の構え（赤く光る）→ 攻撃 → 戻り」を繰り返します。
  - 構え中・戻り中の敵を突くと倒せます。
  - 盾を構えた敵を突くと弾かれ、反撃されることがあります。
  - 突いている最中に敵の攻撃が来ると、味方がやられます。
- 盾は左手に持つので、自分の盾は左隣を守ります。右隣が空くと、守っていても危なくなります。
- 守ってばかりいると敵の増援が増え、じわじわ押し下げられます。
- 敵陣まで押し返せば勝ち。後ろの線まで押されるか、隊が尽きたら負け。
