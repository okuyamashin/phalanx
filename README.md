# Phalanx

盾を並べて守り、号令で一斉に突く。古代ギリシャの重装歩兵の密集隊形（ファランクス）をテーマにした、ブラウザで動く小さなゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールは不要です。

- **スペースキー（またはクリック／タップ）**：隊全体で一斉に突く
- **それ以外**：ずっと盾で守る（突いている間だけ無防備になる）
- **R キー**：リセット

## ルール

- 味方は横一列に並び、倒れると後ろの予備兵が前に出て埋めます。
- 敵は一人ずつバラバラのタイミングで「守り → 攻撃の構え（赤く光る）→ 攻撃 → 戻り」を繰り返します。
  - 構え中・戻り中の敵を突くと倒せます。
  - 盾を構えた敵を突くと弾かれ、反撃されることがあります。
  - 突いている最中に敵の攻撃が来ると、味方がやられます。
- 盾は左手に持つので、自分の盾は左隣を守ります。右隣が空くと、守っていても危なくなります。
- 守ってばかりいると敵の増援が増え、じわじわ押し下げられます。
- 敵陣まで押し返せば勝ち。後ろの線まで押されるか、隊が尽きたら負け。
