# Sounds

すべて [Kenney](https://kenney.nl)（CC0）の素材です。名前を変えてコピーしています。

| ファイル | 元のパック | 元のファイル | 使いどころ |
|---|---|---|---|
| `shield_bronze_0〜4.ogg` | Impact Sounds | `impactPlate_heavy_000〜004.ogg` | 敵の攻撃を青銅の盾で受けた |
| `shield_wicker_0〜4.ogg` | Impact Sounds | `impactWood_heavy_000〜004.ogg` | 突きが編み細工の盾に弾かれた |
| `hit_0〜4.ogg` | Impact Sounds | `impactPunch_heavy_000〜004.ogg` | 敵を突き倒した |
| `fall_0〜4.ogg` | Impact Sounds | `impactSoft_heavy_000〜004.ogg` | 味方が倒れた |
| `clatter_0〜2.ogg` | Impact Sounds | `impactMetal_light_000〜002.ogg` | 倒れた味方の盾が地面に当たる |
| `step_0〜4.ogg` | RPG Audio | `footstep00〜04.ogg` | 号令で隊が踏み込む |

`_candidates/` はパック全体を手元で聞き比べるためのもので、公開していません（`tools/sound-board.html` で聞けます）。
